# Poli-Tutor

Poli-Tutor is a Socratic tutor, powered by a RAG system. It combines a FastAPI backend, a React frontend and a ChromaDB Cloud vector store to answer student questions using the indexed course documents as context.

The project is designed around one teaching rule: the assistant should guide the student with questions and hints instead of giving direct answers.

## What It Does

- Ingests course documents in PDF, PPTX and Markdown format.
- Extracts text, tables and relevant images with the Unstructured API.
- Summarises useful images with an LLM before embedding them.
- Stores multilingual embeddings in ChromaDB Cloud.
- Retrieves course-specific context and reranks it with a reranker.
- Generates Socratic tutor responses through OpenRouter.
- Provides short and long-term memory.
- Uses guardrails to block prompt-injection attempts, direct-answer requests and overly direct tutor outputs.
- Provides teacher/admin dashboards, reporting, course management and user management through the backend API.
- Includes retrieval, threshold and tutor-quality evaluation scripts.

## Quick Start

The normal local path is Docker Compose. It runs the frontend, backend and Redis without requiring local Python, Node or Redis installs.

```bash
cp app/backend/.env.example app/backend/.env
cp rag/.env.example rag/.env

docker compose up --build
```

Then open:

- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- API docs: http://localhost:8000/docs

The project still depends on external services configured through environment variables:

- MongoDB Atlas, configured in `app/backend/.env`
- ChromaDB Cloud, configured in `rag/.env`
- OpenRouter, configured in `rag/.env`
- Unstructured API, only needed when running ingestion

Full setup instructions are in [docs/RUNNING.md](docs/RUNNING.md).

## API

The API is exposed under:

```text
http://localhost:8000/api/v1
```

Interactive documentation is generated by FastAPI:

```text
http://localhost:8000/docs
```

The current route groups are authentication, users, courses, chats, messages, reports, analytics and memory.
